# Kitchen Control

Планшетное приложение для ресторана: склад, закупки, тех. карты, команда, подрядчики, санитарный контроль.
Приложение самодостаточно (HTML/CSS/JS без сборки), данные хранятся на устройстве (localStorage), демо-данные — в `data.js`.
Запуск: открыть `index.html`. Параметры для демо: `?role=chef&route=stock&nosplash`.

Демо-видео: `docs/demo.mp4` · скриншоты: `docs/screens/` · автотест: `node tests/kitchen.mjs`.

## Роли
| Роль | Видит | Деньги | Согласует заявки |
|---|---|---|---|
| Руководитель | всё, аналитика | да | да |
| Управляющий | всё, аналитика | да | да |
| Менеджер | заявки, команда, подрядчики, склад, контроль | да | нет (заявка → «согласование») |
| Шеф-повар | склад, закупки, тех. карты, контроль, команда | да | да |
| Су-шеф | склад, закупки, тех. карты, контроль | **скрыты (•••)** | нет |

Цепочка работает сквозняком: су-шеф формирует заявку → шеф согласует → поставка → приёмка пополняет склад → списание по тех. карте уменьшает остатки → всё попадает в аналитику.

## Оценка удобства (что проверено, а что нет)
Проверено автоматически (Chromium, 1180×820 и 820×1180):
- все зоны касания ≥ 44 px (аудит скриптом по всем экранам и вкладкам);
- нет горизонтальной прокрутки в вертикальном положении; нет ошибок JS на всех экранах всех ролей;
- сквозные сценарии (списание, заявка → согласование → приёмка, замер вне нормы, чек-лист, формы) — `tests/kitchen.mjs`;
- ввод чисел — крупная цифровая клавиатура, а не системная (не перекрывает экран, удобно мокрыми руками);
- моушн: заставка, плавная смена экранов, счётчики, кольца, графики; при «уменьшить анимацию» в системе отключается.

**Не проверено** — нужен живой планшет и 1–2 сотрудника кухни: реальная читаемость на кухне при свете, ввод в перчатках, скорость на слабом железе, понятность терминов персоналу. Рекомендую 15-минутный тест: попросить су-шефа провести приёмку и замер температуры без подсказок и засечь время.

Известные слабые места: данные только на одном устройстве; таблица склада на 28 позициях ок, на сотнях понадобится группировка/пагинация; график смен без учёта часов/ставок; нет авторизации по PIN (роль выбирается свободно — для боевого использования нужен PIN на роль).
