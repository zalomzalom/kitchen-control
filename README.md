# Kitchen Control

Планшетное приложение для ресторана: склад, закупки, тех. карты, команда, подрядчики, санитарный контроль.
Приложение самодостаточно (HTML/CSS/JS без сборки), данные хранятся на устройстве (localStorage), демо-данные — в `data.js`.
Запуск: открыть `index.html`. Параметры для демо: `?role=chef&route=stock&nosplash`.

Демо-видео: `docs/demo.mp4` · скриншоты: `docs/screens/` · автотест: `node tests/kitchen.mjs`.
Телефон: адаптивная раскладка (нижнее меню, карточки вместо таблиц) — `docs/phone/`.

## Роли
| Роль | Что видит | Деньги | Согласует заказы |
|---|---|---|---|
| Руководитель | Главная, Деньги, Склад, Закупки, Команда, Проверки | да | да |
| Управляющий | то же | да | да |
| Менеджер | Главная, Закупки, Команда, Проверки, Склад | да | нет |
| Шеф-повар | Главная, Склад, Закупки, Блюда, Проверки | да | да |
| Су-шеф | Главная, Склад, Закупки, Проверки | скрыты (•••) | нет |
| **Повар** | **4 крупные кнопки, без меню**: списать продукт, записать температуру, мои задачи, что использовать первым | скрыты | нет |

Вход — по PIN (демо: 1111 у всех). Через 10 минут без касаний планшет блокируется. Подсказки (3 экрана) показываются при первом входе каждой роли.

## Принципы простоты
- Главная — это список дел «Что сделать сейчас». У каждого дела своя кнопка (Списать, Заказать, Принять, Согласовать, Записать замер…), заходить в разделы не нужно.
- Ошиблись — внизу 8 секунд есть «Отменить» (списание, приёмка, согласование, замер, визит и др.).
- Простые слова вместо терминов: «себестоимость блюд», «что использовать первым», «блюда».
- Разделов не больше шести; подрядчики внутри «Проверок», поставщики внутри «Закупок», итоги и блюда внутри «Денег».
- Напоминание о замерах температуры 3 раза в день (8:00, 14:00, 20:00) показывается в ленте дел и на значке раздела.
- Голосовой ввод в «Списать продукт»: «списать два килограмма свинины» (нужен Chrome/Safari и разрешение микрофона).
- Фото при списании, приходе и приёмке (сжимаются, хранятся последние 25).

## Синхронизация планшетов
Профиль → «Общие данные»: «Включить» выдаёт код заведения из 8 символов, на другом планшете — «Ввести код». Данные хранятся в Durable Object на Cloudflare, планшеты опрашивают сервер раз в 5 секунд.
Ограничение: при одновременной записи с двух планшетов побеждает тот, кто записал первым; второй получит свежие данные и его последнее действие надо повторить. Код заведения — единственная защита, его нельзя публиковать.

## Проверка
`node tests/kitchen.mjs` — все роли и сценарии; с `KC_URL=http://localhost:8799` (запущенный `npx wrangler dev --local --port 8799`) ещё и синхронизация двух планшетов.

## Выкладка (Cloudflare Workers)
Сайт: https://kitchen-control.fixclean.workers.dev
Обновить: `node build.mjs && npx wrangler deploy` (нужен `CLOUDFLARE_API_TOKEN`).
Весь сайт собирается в один Worker (`dist/worker.js`), а не в статические файлы: так выкладка работает через обычный API-токен.
